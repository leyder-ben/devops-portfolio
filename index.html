I'm a Cloud & DevOps Engineer with a hands-on focus on AWS infrastructure, automation, and production-grade deployment patterns. My approach is straightforward: build real things, encounter real problems, and solve them — because that's where the actual learning happens.

My work spans the full infrastructure stack — from provisioning VPCs and ECS clusters with Terraform, to building parallel CI/CD pipelines with Jenkins and GitHub Actions, to containerizing applications with Docker and deploying them on AWS Fargate. My first featured project put 45 AWS resources into production in under 72 hours, including two independent deployment pipelines and a load-tested architecture that held 99.9% availability under 250 concurrent users.

Beyond deployment, I think deeply about why infrastructure succeeds or fails at an organizational level — not just the technical side. My second project is a strategic analysis of the five most common failure points in cloud engineering teams, grounded in AWS tooling and real-world change management. Understanding the human and process dimensions of engineering is what separates systems that hold up from ones that don't.

I work best in environments that value reliability, good engineering practice, and building things that actually run in production.
